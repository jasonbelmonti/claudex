# @jasonbelmonti/claudex 4.0.0 Release Notes

Version 4.0.0 applies the July 2026 provider SDK refresh and raises the
supported Node runtime floor to match `@github/copilot-sdk@1.0.5`.

## Breaking Changes

- The supported Node runtime floor changes from `engines.node >=20` to
  `engines.node ^20.19.0 || >=22.12.0`.
- Consumers on early Node 20 releases must upgrade to Node 20.19.0 or newer.
- Consumers on early Node 22 releases must upgrade to Node 22.12.0 or newer.

This runtime floor follows the stable `@github/copilot-sdk@1.0.5` engine
contract. No public `claudex` TypeScript API change is expected from the
provider SDK refresh itself.

## Dependency Refresh

- `@anthropic-ai/claude-agent-sdk` updates to `0.3.201`.
- `@anthropic-ai/sdk` updates to `0.110.0`.
- `@github/copilot-sdk` updates to `1.0.5`.
- `@openai/codex-sdk` updates to `0.142.5`.
- `@modelcontextprotocol/sdk` remains on `1.29.0`, now as an exact root
  dependency pin.

## Validation Before Tagging

Run the deterministic release gates on the release-prep branch before creating
the `v4.0.0` tag:

```bash
npm ci
npm run ci
npm run package:check
npm run check
npm audit --audit-level=moderate
```

Authenticated smoke tests remain optional release evidence because they depend
on local provider availability:

```bash
npm run test:smoke
```
